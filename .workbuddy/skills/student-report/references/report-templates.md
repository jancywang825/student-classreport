# 报告口吻与润色规范（v0.4）

脚本已按老师口吻生成草稿；如需润色，遵守：

1. **口吻**：**老师对学生和家长汇报的口吻**（类飞书课次记录风格），温和、具体、有依据；先肯定后建议；不堆砌形容词。
2. **禁用字眼**：「AI」「检索」「自动生成」「快照转录」「demo」「接口鉴权」「数据来源」等机器味表述；一律改为老师视角的自然表达（如「结合课堂反馈」「从这几次课的表现看」）。
3. **事实约束**：所有数字（出勤次数、星星数、完成率、错题号、评级）必须与数据一致，润色不得改动事实与数字；数据缺失就写「暂未记录」，不得编造。
4. **表扬（D6/S5）**：必须覆盖 ①课程出勤 ②课堂互动参与 ③课堂小黑板 三个维度，各给一条具体事实。
5. **小黑板分析（S3/D11）**：单独成段，包含
   - 完成概况（是否完成、书写/作图/解题过程情况，含**小黑板正确率**）；
   - **值得表扬的点**（1–3 条，具体到书写、作图、方法运用；**附作答正确的小黑板原图**）；
   - **可以提升的点**（1–3 条，来源于学情沟通/评级/错题，与表扬不矛盾；**附作答错误或未写的小黑板原图**，暂无此类图时用文字说明兜底，不得用其他学员的图代替）。
6. **单次课堂报告结构（B，v0.4）**：**不再有「本次课堂学习记录」独立小节**（出勤/评级/星星/作业已在头图信息卡与指标色卡中呈现）；小节顺序为 课堂亮点 → 小黑板完成情况与分析 → 我们一起努力的方向 → 下次课小目标。
7. **头部字段（v0.3）**：课程名称用**课程全称**；**主讲老师与联席老师分列展示（两个角色，缺一不可）**；主讲正式版从接口获取，demo 用「XX老师」；**不出现课程类型**。
8. **视觉规范（v0.4，参考「创作者周报」式 UI）**：
   - 首页顶部**绿色渐变头图**：大号白色标题「{学员}学习报告」+ 副标题（课次/周期 · 报告类型）+ 课程全称信息行；
   - 浅灰底色 + 白色圆角卡片分节；指标用「大号彩色数字 + 小灰标签」白色色卡，**必含「小黑板正确率」**；
   - 模块间距大、字间距/行间距放宽，避免阅读压迫感；
   - 关键信息用彩色字体或底色突出：正向/评级=绿、星星/亮点=琥珀、出勤/作业=蓝、提醒/提升=橙。
9. **努力方向（D7/S7）**：1–3 条，来源于学情沟通/错题/评级。
10. **小目标（D8/S8）**：1–2 条，具体、一周内可达成、可验证。
11. **协同动作（D9）**：分「我们（机构侧）」与「您（家长侧）」两栏，各 1–3 条，与小目标呼应。
12. **隐私**：只写该学员数据，不出现其他学员姓名与对比排名。
13. **落款**：结尾附主讲老师姓名与生成日期。
